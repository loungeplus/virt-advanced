= Experience OpenShift Virtualization: Advanced Operations and Automation

== はじめに

今日のダイナミックなIT環境において、組織は従来の仮想化管理の複雑さとクラウドネイティブ・イノベーションの要求との両立に苦慮しています。このワークショップでは、Red Hat OpenShift VirtualizationとAnsible Automation Platform、そしてRed Hat Advanced Cluster Management for Kubernetesを組み合わせることで、仮想環境でもコンテナベースでも、あらゆるワークロードに対応する統合型、効率的、かつ安全なプラットフォームを実現する方法を示し、ITプロフェッショナルがこうしたハイブリッドな現実に自信を持って対応できるよう支援します。

このラボは、大変ご好評いただいている https://www.redhat.com/en/events/na-red-hat-openshift-virtualization[Experience OpenShift Virtualization Roadshow^]ラボの続編です。導入後2日目以降、環境を管理し、仮想マシン管理者に求められる重要な運用タスクを実行するための知識とツールを習得していただきます。これにより、仮想化ワークロードを初期導入後も長期間にわたって効率的に管理・保守できるようになります。


=== バージョン情報

このラボは、以下のソフトウェアバージョンを使用して開発されました。

* Red Hat OpenShift 4.18.23
* Red Hat OpenShift Virtualization 4.18.13
* Red Hat Ansible Automation Platform 2.5
* Red Hat Advanced Cluster Management for Kubernetes 2.14.0

(Accurate as of Sep 18, 2025)
