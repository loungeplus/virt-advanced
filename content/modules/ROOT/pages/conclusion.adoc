== 重要なポイント

* OpenShift Virtualization はソリューション指向であり、成熟度、安定性、拡張性に優れ、導入しやすいソリューションを提供します。

* Ansible Automation Platform は、仮想マシン環境の多くの機能を大規模に自動化および管理できるエンタープライズツールです。

* Red Hat Advanced Cluster Management for Kubernetes は、管理者に仮想環境全体を一元管理できる単一の画面を提供することで、大規模な分散型企業が直面する課題の解決を支援します。

=== Red Hat ラーニングサービス: DO317 Red Hat OpenShift Virtualization を使用した仮想マシンの管理

* OpenShift クラスター上での VM の作成、アクセス、管理に必要なスキル。
* コンテナのリソース使用とアクセスを制御するのと同じ Kubernetes 機能を使用して、VM からの CPU、メモリ、ストレージ、ネットワークリソースの使用とアクセスを制御するために必要なスキル。
* Kubernetes の標準機能と OpenShift Virtualization の拡張機能を使用して、VM の高可用性 (HA) を管理するためのサンプルアーキテクチャ。
* OpenShift 上の VM を、ストレージやデータベースなど、OpenShift クラスター外部のデータセンターサービスに接続するための戦略。
* Migration Toolkit for Virtualization オペレーターを使用して、互換性のあるハイパーバイザーから OpenShift Virtualization に VM を移行するための戦略。

https://www.redhat.com/en/services/training/managing-virtual-machines-red-hat-openshift-virtualization-exam[こちら^] をクリックして確認してください。
