= 仮想マシンの自動作成

== はじめに

このモジュールではOpenShiftのプロジェクトに、特定のboot sourceを利用して仮想マシンを自動的に作成する方法を学習します。

== Ansible Automation Platform の認証情報

Ansible Automation Platform コンソールは {aap_controller_web_url}[こちら^] からご利用いただけます。

管理者ログインは次の認証情報で利用できます。

* *User:* `{aap_controller_admin_user}`
* *Password* `{aap_controller_admin_password}`

image::module-04-virt-automation/01-aap_login.png[title="AAP Login", link=self, window=blank, width=100%]

NOTE: Ansible Automation Platform コンソールでは、セキュリティ上の理由から、管理者ユーザーには5分間のタイムアウトが設定されています。誤ってログアウトしてしまった場合は、上記の認証情報を使用して再度ログインできます。

== Red Hat OpenShift コンソールの認証情報

OpenShift クラスターコンソールは {openshift_cluster_console_url}[こちら^] からご利用いただけます。

* *User:* `{openshift_cluster_admin_username}`
* *Password:* `{openshift_cluster_admin_password}`

最初に認証プロバイダーを選択するように求めるページが表示されるので、*htpasswd_provider* をクリックします。

image::module-01-perf-scale-ts/00-htpasswd_login.png[title="OpenShift Authentication", link=self, window=blank, width=100%]

次に、認証情報をコピー/ペーストできるログイン画面が表示されます。

image::module-01-perf-scale-ts/01-openshift_login.png[title="OpenShift Login", link=self, window=blank, width=100%]

[[AAP_Project]]
=== Ansible Automation Platformプロジェクトの作成

Ansible Automation Platformのプロジェクトは、Ansibleのコード（Playbookやロール）が保管されている場所を定義するものです。

. AP UIダッシュボード内で、左側のメニューから *Automation Execution* のメニューをクリックして展開し、*Project(プロジェクト)* をクリックします。*Create Project(プロジェクトの作成)* をクリックします。
+
image::module-06-virt-automation/02-create_project_01.png[title="Ansible Project", link=self, window=blank, width=100%]
+
image::module-06-virt-automation/02-create_project_02.png[title="Create Ansible Project", link=self, window=blank, width=100%]
+
. *プロジェクトの作成* フォームの次のフィールドに適切な値を入力するか、ドロップダウン メニューから選択します。
   * *Name(名前):* `Auto Deploy VMs`
   * *Organization(組織):* Default
   * *実行環境:* Day2 EE
   * *ソースコントロールのタイプ:* Git
   * *ソースコントロールのURL:* https://github.com/loungeplus/aap-demos.git

+
. 下部の *プロジェクトの作成* をクリックします。
+
image::module-06-virt-automation/02-create_project_03.png[title="Input Ansible Project", link=self, window=blank, width=100%]
+
. *最終ジョブステータス* が *成功* になるまで待ちます。
+
image::module-06-virt-automation/02-create_project_04.png[title="Job Status Success", link=self, window=blank, width=100%]

[[create_template]]
== テンプレートの作成

=== Ansible Automation Platform を使用した VM ジョブテンプレートの作成

このセクションでは、Ansible Automation Platform ダッシュボードを活用し、VMの作成を行うテンプレートを作成します。

このテンプレートは、OpenShiftのプロジェクト *development* または *staging* に、OSのタイプが *fedora* *rhel9* *rhel10* のいずれかの仮想マシンを任意の名前で作成するものです。
Playbookは https://github.com/loungeplus/aap-demos.git[Github^] にある virt-vm-depoly.yaml を利用します。

. AAP UIダッシュボード内で、左側のメニューから *Automation Execution* に移動し、*Templates(テンプレート)* をクリックします。テンプレート画面で *Create template(テンプレートの作成)* ボタンをクリックし、ドロップダウンメニューから *Create job template(ジョブテンプレートの作成)* を選択します。
+
image::module-06-virt-automation/03-create_template_01.png[title="Create Template", link=self, window=blank, width=100%]
+
image::module-06-virt-automation/03-create_template_02.png[title="Job Template", link=self, window=blank, width=100%]
+
. *Create job template(ジョブテンプレートの作成)* ページで次の詳細を入力します。
+
image::module-06-virt-automation/03-create_template_03.png[title="Input Job Template", link=self, window=blank, width=100%]

+
|===
| Parameter         | Value

| Name(名前)          | `Auto Deploy VMs`
| Job Type(ジョブタイプ)      | Run(実行)
| Inventory(インベントリー)     | Demo
| Project(プロジェクト)       | Auto Deploy VMs
| Playbook      | virt-aap-day2/virt-vm-depoly.yaml
| Execution Environment(実行環境) | Day2 EE
| Credentials(認証情報)   | OpenShift Credential
|===
+

. 入力が完了したら、*Create job template(ジョブテンプレートの作成)* ボタンをクリックします。
+

image::module-06-virt-automation/03-create_template_04.png[title="Input Job Template", link=self, window=blank, width=100%]
. テンプレートが作成されました。

+
image::module-06-virt-automation/03-create_template_05.png[title="Create Job Template", link=self, window=blank, width=100%]
+
. ジョブ テンプレートが作成されたら、右上部の *Survey* ボタンをクリックします。Survey機能とは、ジョブテンプレートを実行する直前に、ユーザーに対して対話形式で入力を求めるカスタム画面を作成できる機能です。
+
image::module-06-virt-automation/04-create_survey_00.png[title="Create Survey", link=self, window=blank, width=100%]
+

. *create survey question* をクリックします。
+
image::module-06-virt-automation/04-create_survey_01.png[title="Create Survey OS type 1", link=self, window=blank, width=100%]
+
.  フォームにOS typeの選択肢を入力します。Multiple Choiceの入力は、値を入力してエンターを押すことで複数登録することができます。また、ここで指定している値は、OpenShiftコンソールで[Virtualization]-[Catalog]を確認した際に表示されるVolume nameになります。
+
|===
| Parameter         | Value

| Question          | OS type
| Answer variable name     | target_os_type
| Answer type    | Multiple Choice(single select)
| Multiple Choice       | fedora (同様に rhel9 rhel10 も選択肢に追加）
|===
+
. 入力が正しいことを確認して、下部の *create survey question* をクリックします。
+
image::module-06-virt-automation/04-create_survey_03.png[title="Create Survey OS type 2", link=self, window=blank, width=100%]
+
image::module-06-virt-automation/04-create_survey_04.png[title="Create Survey OS type 3", link=self, window=blank, width=100%]
+
. `Survey disabled` となっているトグルボタンを `Survey enabled` に変更して機能を有効化します。
+
image::module-06-virt-automation/04-create_survey_05.png[title="enable Survey", link=self, window=blank, width=100%]
+

+
. 続けて *create survey question* をクリックして、フォームに次の値を入力します。VMの名前をテキストで入力できるようにするものです。
+
|===
| Parameter         | Value

| Question          | VM Name
| Answer variable name     | vm_name
| Answer type    | text
|===
+
. 入力が正しいことを確認して、下部の *create survey question* をクリックします。
+
image::module-06-virt-automation/04-create_survey_06.png[title="Create Survey VM name", link=self, window=blank, width=100%]
+
. 続けて *create survey question* をクリックして、フォームに次の値を入力します。Multiple Choiceの入力は、値を入力してエンターを押すことで複数登録することができます。先に作成したOpenShiftのプロジェクト *development* と *staging* を選択肢とします。

+
|===
| Parameter         | Value

| Question          | Namespace
| Answer variable name     | vm_namespace
| Answer type    | Multiple Choice(single select)
| Multiple Choice       | development (同様に staging も選択肢に追加）
|===
+ 

. 入力が正しいことを確認して、下部の *create survey question* をクリックします。
+ 
image::module-06-virt-automation/04-create_survey_08.png[title="Create Survey Namespace", link=self, window=blank, width=100%]

+ 
. ３つの *survey* が設定されたテンプレートが作成されました。
+ 
image::module-06-virt-automation/04-create_survey_09.png[title="3 Survey Template", link=self, window=blank, width=100%]


[[run_template]]
== Ansible Automation Platform を使用した ジョブテンプレートの実行

. ジョブテンプレートを作成したら、右上の *Launch template(テンプレートの起動)* ボタンを選択してジョブを実行します。
+
image::module-06-virt-automation/05-run_template_01.png[title="Run Template", link=self, window=blank, width=100%]
+
. Surveyで作成した質問が表示されるので、適切な値を選択するか、入力します。入力後に *Next* ボタンをクリックします。
+
image::module-06-virt-automation/05-run_template_03.png[title="Input Survey", link=self, window=blank, width=100%]
+
. 変数がセットされていることを確認し、*Finish* ボタンをクリックします。

+
image::module-06-virt-automation/05-run_template_04.png[title="Finish Template", link=self, window=blank, width=100%]
+

. テンプレートが実行され、出力に *成功* と表示されるまで待ちます。

+
image::module-06-virt-automation/05-run_template_05.png[title="Success Template", link=self, window=blank, width=100%]
+

. OpenShiftコンソールに戻り、仮想マシンが作成されているか確認します。テンプレートの実行後、指定したOpenShiftプロジェクト内に、該当のVMが作成されたことを確認できます。
+
image::module-06-virt-automation/06-result_01.png[title="deployed VM", link=self, window=blank, width=100%]
